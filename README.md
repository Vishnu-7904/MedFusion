# MedFusion: Unified AI Framework for Patient Interaction and Clinical Intelligence

## Overview

MedFusion is a multimodal clinical intelligence system that combines medical image understanding and clinical report generation. The project integrates Vision Transformer (ViT), DistilGPT2, and OpenAI Whisper to assist healthcare workflows through automated image captioning and clinical intelligence generation.

## Features

- Medical image caption generation
- Clinical report generation
- Multimodal healthcare data processing
- Deterministic fusion engine
- BLEU and ROUGE based evaluation

## Technologies Used

- Python
- PyTorch
- Transformers
- OpenAI Whisper
- Vision Transformer (ViT)
- DistilGPT2
- Pandas
- Jupyter Notebook

## Project Structure

- `xray_captioning.ipynb` – Medical image caption generation
- `imaging_project.ipynb` – Image processing pipeline
- `fusion_data_prep.ipynb` – Data preparation
- `conversational_project_updated.ipynb` – Conversational workflow
- `captions` – Generated captions
- `cuis` – Clinical concept mappings
- `output_with_CUIs` – Processed output dataset
- `Med-Fusion Paper.pdf` – Research publication

## Results

- ROUGE-L: 0.62
- BLEU-1: 0.30
- Generated clinical reports using a deterministic rule-based fusion engine
- Successfully deployed on consumer-grade hardware
